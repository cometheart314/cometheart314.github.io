Yajiri とは

読んだもの・調べたことを、そのまま Obsidian のノートにするアプリです。

どのアプリでも、残したい文章やファイルを Yajiri に送ると、AI が題名・要約・タグを付け、vault の中から保存先のフォルダと関連するノートを選びます。内容を確かめて「保存」を押すと、Markdown のノートとして vault に入ります。

  • 1文章を選ぶか、ファイルを選んで Yajiri に送る
  • 2AI が整理する（数秒〜数十秒）
  • 3確かめて、直したいところだけ直して保存

Yajiri がめざしているのは、あなた専用の「AI のためのデータベース」を Obsidian に育てることです。考え方は「Yajiri の考え方」で説明しています。

Yajiri は、はじめに選んだ vault のフォルダの中にだけノートを書き込みます。同じ名前のノートがあっても上書きせず、別の名前で保存します。

登録のしかた

文章を選んで送る

Safari、メール、プレビュー、Word など、どのアプリでも使えます。

  1. 残したい文章を選びます。
  2. 右クリックして「サービス」→「Yajiri に送る」を選びます。

選んだ部分に書式や画像があれば、見出しや箇条書きは Markdown にし、画像はノートに添付します。「サービス」に Yajiri が出ていないときは「右クリックのメニューに出す」を見てください。

ファイルを送る

  • Finder でファイルを右クリックして「サービス」→「ファイルを Yajiri に送る」
  • メニューバーの Yajiri のアイコン →「ファイルを選んで登録…」
  • Dock の Yajiri のアイコンにファイルをドロップ

1 つのファイルにつき登録パネルが 1 枚開きます。6 個以上をまとめて送ったときは、先頭の 5 個だけにするかを聞かれます。

コピーした文章を登録する

文章をコピーしてから、メニューバーの Yajiri のアイコン →「コピーした文章を登録」を選びます。

読み込めるファイル

種類取り込まれるもの
PDF本文と画像。文字の無いページ（スキャンしたものなど）は、写っている文字を読み取ります
Word（.docx / .doc）、OpenDocument（.odt）見出し・箇条書き・リンク・表などの書式と画像
RTF / RTFD（テキストエディット、Jedit など）書式と画像
HTML、Web アーカイブ書式と画像
画像画像を添付し、写っている文字を読み取って本文に入れます
テキスト、Markdown、プログラムのファイルそのまま（プログラムはコードブロックにします）

ファイルは 64 MB まで、本文は 20 万文字までです。それより長い本文は途中までを取り込みます。

登録パネル

AI が整理し終わると、パネルの上に「〜で整理しました」と出ます。どの欄も自由に直せます。

題名
ノートの名前になります。
要約
本文の内容を 1〜3 文でまとめたもの。frontmatter の summary に入ります。
タグ
× で外し、「＋ タグを追加」で足します。設定の「いつも付けるタグ」は毎回入ります。
保存先
vault の中のフォルダ。AI が選べなかったときは、設定の「既定の保存先」になります。
添付する画像
ノートに添付する画像です。要らない画像は右上の × で外します。画像は Obsidian の「添付ファイルの場所」の設定どおりに保存されます。
関連ノート
vault の中で内容が近いノート。ノートの末尾に「関連」としてリンクが入ります。
詳しく
種類・日付・「ファイル名の先頭に日付を付ける」・本文を確かめられます。Claude の API キーを入れていれば、「Claude で Markdown に整形」で本文の体裁を整えられます（要約はせず、内容はそのまま残します）。

右上の ↻ から、この 1 件だけ別の AI で整理し直せます。ふだんは Apple Intelligence を使い、長い文章のときだけ Claude で整理し直す、という使い方ができます。

「保存」（⌘↩）でノートを書き込みます。

Apple Intelligence と Claude の違い

Yajiri は 2 つの AI から選べます。同じ文章でも、どちらで整理するかで結果がかなり変わることがあります。

Apple IntelligenceClaude
料金無料使った分だけ、ご自身の API キーに請求されます
内容の送り先Mac の外に出ませんAnthropic 社の Claude API に送られます
必要なものApple Intelligence に対応した Mac で、Apple Intelligence をオンにしておくAnthropic の API キーと、インターネットへの接続
AI が読む本文約 1,800 文字
長い文章は、冒頭と各節の書き出しを抜き出して渡します		3 万文字まで
保存先・関連ノートの候補本文に近いものを、それぞれ 20 件まで選んで渡しますvault のフォルダとノートをすべて渡します
得意なもの短い〜中くらいの文章（Web の記事、メモ、メール）長い書類、いくつもの話題が入った文章（メールマガジン、報告書、論文）
本文を Markdown に整形できませんできます

結果が違うのはなぜか

1. 読める文章の量が違う

Apple Intelligence は Mac の中で動く小さな AI で、一度に扱える量が限られています（指示と答えを合わせて、日本語でおよそ 4,000 文字ぶん）。そのため Yajiri は、本文を約 1,800 文字に縮めてから渡しています。

短い文章なら、どちらも全文を読むので差はあまり出ません。いくつもの話題が入った長い文章では、Apple Intelligence は一部しか読めないので、要約やタグが前半の話題に偏ることがあります。

2. 選べる候補の数が違う

Apple Intelligence には、vault のフォルダとノートを全部は渡せません。Yajiri が本文と名前の似ているものを 20 件ずつ選んで渡し、AI はその中から選びます。名前の書き方が本文と大きく違うフォルダやノートは、候補に入らないことがあります。

Claude にはすべてを渡すので、名前が少し違っても（たとえば「ザックバラン」と「ざっくばらん」）同じものだと分かって選べます。

3. AI の大きさが違う

Apple Intelligence は Mac の中で動かすために小さく作られた AI です。Claude は Anthropic のデータセンターで動く大きな AI で、文章の意味をつかむ力や、ものごとの知識に大きな差があります。題名に連載の名前を入れる、何の文章か（メールマガジンなど）を見分ける、といった判断は Claude のほうが得意です。

どちらを選べばよいか

Apple Intelligence がおすすめ

  • 料金をかけたくない
  • 内容を Mac の外に出したくない
  • 主に Web の記事やメモなど、短めの文章を残す

Claude がおすすめ

  • 長い書類や PDF、メールマガジンをよく残す
  • 保存先や関連ノートの選び方の精度を上げたい
  • 本文を読みやすい Markdown に整えたい

迷ったら、ふだんは Apple Intelligence にしておき、結果が物足りないときだけ登録パネルの ↻ から「Claude で整理し直す」を選ぶのがおすすめです。API キーを入れておけば、設定を切り替えなくても 1 件ずつ使い分けられます。

Claude のモデル

設定の「AI」で選べます。

Claude Sonnet 5.5速さと賢さのバランスが良く、ふだん使いにおすすめ（既定）
Claude Opus 5.5いちばん賢い。料金は高め
Claude Haiku 4.5速くて安い

1 件あたりの料金は、文章の長さとモデルによって変わります。使った量と料金は Anthropic のコンソールで確かめられます。

Claude を使う準備

  1. Anthropic のコンソールでアカウントを作り、支払い方法を登録します。
  2. 「API Keys」で API キーを作り、コピーします（sk-ant- で始まる文字列です）。
  3. Yajiri の設定 →「AI」で「Claude」を選び、API キーを貼り付けて「確認」を押します。「使えます。」と出れば準備完了です。

API キーは Mac のキーチェーンに保存され、Anthropic 以外には送りません。はじめて Claude に送るときは、内容を Anthropic に送ってよいかを確かめるダイアログが出ます。

設定

メニューバーの Yajiri のアイコン →「設定…」（⌘,）で開きます。

一般

  • vault・既定の保存先：ノートを書き込む vault と、AI が保存先を選べなかったときのフォルダ
  • 保存したら Obsidian で開く
  • 整理が終わったときの音
  • Dock にアイコンを表示：オフにすると、メニューバーだけで動きます
  • ログイン時に起動

AI

Apple Intelligence と Claude の切り替え、Claude の API キーとモデル。

ノート

  • 種類：AI が選ぶノートの種類の一覧（frontmatter の type）。名前を押すと直せ、行をドラッグすると並べ替えられます。一番上が既定です。
  • いつも付けるタグ：カンマで区切って書きます。
  • 本文の先頭に題名の見出し（# 題名）を入れる
  • 関連するノートを探してリンクする

右クリックのメニューに出す

ふつうは入れた直後から、右クリックの「サービス」に「Yajiri に送る」が出ます。出ないときは、次のようにオンにします。

  1. システム設定 →「キーボード」を開きます。
  2. 「キーボードショートカット…」を押し、左の一覧から「サービス」を選びます。
  3. 「テキスト」の中の「Yajiri に送る」をオンにします。
  4. 「ファイルとフォルダ」の中の「ファイルを Yajiri に送る」をオンにします。

同じ画面で、それぞれにキーボードショートカットを割り当てることもできます。Yajiri の設定 →「一般」→「右クリックのメニューに出す方法…」からも、この画面を開けます。

困ったとき

「Apple Intelligence を使えません」と出る
システム設定の「Apple Intelligence と Siri」でオンにしてください。オンにした直後は、モデルの準備に時間がかかることがあります。対応していない Mac では Claude を使ってください。
「文章が長すぎて Apple Intelligence で扱えませんでした」と出る
保存先や関連ノートの候補が多いと起きることがあります。登録パネルの ↻ から Claude で整理し直すか、題名などを手で入力して保存してください。
要約やタグが文章の一部の話題に偏っている
長い文章では、Apple Intelligence は一部しか読めません（違いの説明）。Claude で整理し直すと、全体を踏まえた結果になります。
AI が整理を断った
内容によっては AI が整理を断ることがあります。題名・タグなどを手で入力すれば、そのまま保存できます。
「API キーが正しくありません」と出る
設定の「AI」で API キーを貼り直し、「確認」を押してください。
「利用上限に達しました」「混み合っています」と出る
少し待ってから ↻ でやり直してください。何度も出るときは、Anthropic のコンソールで利用上限や残高を確かめてください。
ファイルを読み込めない
メニューバーの Yajiri のアイコン →「ファイルを選んで登録…」から、同じファイルを選び直してください。
HTML の画像が取り込まれない
保存した HTML の隣のフォルダにある画像は読めないことがあります。Safari で「Web アーカイブ」形式で保存すると、画像ごと取り込めます。

プライバシー

  • Apple Intelligence：整理はすべて Mac の中で行われ、内容は外に出ません。
  • Claude：整理する文章（または取り込んだファイルの中身）と、vault のノート名・フォルダ名の一覧を、Anthropic 社の Claude API に送ります。送った内容は Anthropic のプライバシーポリシーに従って扱われます。
  • Yajiri が書き込むのは、選んだ vault の中だけです。
