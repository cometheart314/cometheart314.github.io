Yajiri プライバシーポリシー

最終更新日：2026 年 10 月 29 日

株式会社 Artman21（以下「当社」）は、macOS アプリ「Yajiri」（以下「本アプリ」）での利用者の情報の扱いを、次のとおり定めます。

1. 当社が集める情報

当社は、本アプリを通じて利用者の情報を集めません。本アプリには、利用状況の分析、広告、クラッシュレポートを当社に送る仕組みはありません。本アプリに登録した文章・画像・ノートが当社のサーバーに送られることもありません。

2. 本アプリが利用者の Mac に保存する情報

本アプリは、動作に必要な次の情報を利用者の Mac の中だけに保存します。

  • ノート：利用者が登録した文章と画像は、利用者が選んだフォルダ（Obsidian の vault など）に Markdown ファイルとして保存します
  • 設定：選んだフォルダへのアクセス権、使う AI、ノートの種類の一覧などの設定は、本アプリの設定として保存します
  • Claude の API キー：利用者が入力した場合に限り、macOS のキーチェーンに保存します

これらは本アプリを削除するか、設定やファイルを利用者が消すことで取り除けます。

3. AI による整理

本アプリは、登録する内容から題名・タグ・要約・保存先などを提案するために AI を使います。どの AI を使うかは利用者が設定で選べます。

Apple Intelligence（既定）

Apple の Foundation Models を使い、利用者の Mac の中で処理します。内容が当社や Apple に送られることはありません。

Claude（利用者が選んだ場合だけ）

利用者が Claude を選び、自分の API キーを入力した場合に限り、次の情報を Anthropic, PBC の API（api.anthropic.com）に送ります。

  • 登録しようとしている文章（長い場合は先頭の部分だけ）。画像は送りません
  • 内容を受け取ったアプリの名前（例：「Safari」）、ファイルから登録したときはそのファイル名
  • 保存先と関連ノートの候補として、選んだフォルダの中のフォルダ名とノート名
  • 設定にあるノートの種類の一覧

「Claude で Markdown に整形」を押したときも、同じように文章を送ります。

送った情報は、利用者自身の Anthropic のアカウントのもとで扱われ、当社は受け取りません。Anthropic での扱いは、Anthropic のプライバシーポリシーと利用規約によります。

4. ネットワークの利用

本アプリがネットワークにつなぐのは、次の場合だけです。

  • 上の「Claude」を利用者が選んだとき
  • 取り込む文章（Web ページなど）にネット上の画像が含まれていて、その画像をノートに添付するとき。画像の置き場所のサーバーに、ふつうのブラウザと同じように画像を取りに行きます

5. 第三者への提供

当社は利用者の情報を集めないため、第三者に提供することもありません。

6. 子どもの利用

本アプリは子どもから特別に情報を集めることはありません。

7. このポリシーの変更

このポリシーを変更するときは、このページで知らせます。
