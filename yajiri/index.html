Yajiri

読んだもの・調べたことを、そのまま Obsidian のノートに。

使い方を見る サポート

Mac App Store で公開の準備をしています。

AI のためのデータベースを、自分の手元に

読んだもの・調べたことは、そのままでは AI の材料になりません。Yajiri は、それを 1 件ずつ AI が読める形に整え、あなたの Obsidian の vault に蓄えていきます。形式は Google が公開した共通の形式 OKF（Open Knowledge Format）の基本の形。蓄えたノートは、あなたも Obsidian で読み返せ、Claude などの AI にもそのまま渡せます。

なぜ Obsidian と OKF なのか、蓄えると何ができるのか →

どのアプリからでも送れる

Safari、メール、PDF、Word…。文章を選んで右クリックし、「Yajiri に送る」を選ぶだけ。ファイルもそのまま送れます。

AI が整理する

題名・要約・タグを付け、あなたの vault から保存先のフォルダと関連するノートを選びます。

書式も画像もそのまま

見出しや箇条書きは Markdown に、画像はノートに添付。確かめて保存すれば、Obsidian のノートになります。

使い方は 3 ステップ

  • 1残したい文章やファイルを選んで、Yajiri に送る
  • 2AI が題名・要約・タグ・保存先・関連ノートを提案する
  • 3直したいところだけ直して「保存」

PDF、Word、RTF、HTML、Web アーカイブ、画像（写っている文字も読み取ります）など、いろいろなファイルを取り込めます。詳しくはヘルプをご覧ください。

2 つの AI から選べる

Apple Intelligence

無料。内容は Mac の外に出ません。Web の記事やメモなど、短めの文章の整理に向いています。

Claude

長い書類やメールマガジンも全体を踏まえて整理し、本文を Markdown に整形できます。ご自身の Anthropic の API キーで使います。

Apple Intelligence と Claude の違いを詳しく説明しています。

動作環境

  • macOS 26 以降
  • Obsidian の vault（ほかの Markdown のフォルダにも保存できます）
  • Apple Intelligence に対応した Mac、または Anthropic の API キー
